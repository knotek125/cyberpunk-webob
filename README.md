# Cyberpunk 2077 – fanouškovský web

Školní projekt: vícestránkový web o hře **Cyberpunk 2077** v neonovém cyberpunkovém stylu. Vznikl s pomocí umělé inteligence (Claude od Anthropic) a byl postupně verzován na GitHubu.

**Web online:** https://TVUJ-UZIVATEL.github.io/NAZEV-REPOZITARE/

## Struktura

| Soubor | Obsah |
| --- | --- |
| `index.html` | Hlavní stránka: úvod, informace o hře, rychlá fakta |
| `galerie.html` | Galerie pěti původních SVG ilustrací |
| `o-mne.html` | Kdo web vytvořil a proč mě téma baví |
| `zdroje.html` | Externí zdroje, citace AI a použité prompty |
| `style.css` | Jednotný vzhled celého webu |
| `images/` | Ilustrace (SVG) a favicon |

## Technologie

HTML5, CSS3 (grid, flexbox, animace, responzivní design), SVG, písma Orbitron a Rajdhani z Google Fonts.
